# Соответствие требованиям к прайсеру внебиржевых деривативов (РФ)

Обозначения: **✓** — реализовано и покрыто тестами или примером; **◐** — частично (что именно — в
примечании); **✕** — не реализовано. «Шаблон» — `prism/data/templates/<id>.yaml`, «пример» —
`examples/trades/<файл>`; и то и другое — чистая конфигурация, без кода движка.

## Главное функциональное требование

| Требование | Статус | Где |
| --- | --- | --- |
| Разложение: mid, хеджирование и исполнение, кредит, остаток | ✓ | `decomposition/breakdown.py`; плюс модельная неопределённость, FVA/ColVA, KVA; остаток в ₽, % номинала и б.п. годовых |
| Цена ванильной альтернативы с тем же назначением | ✓ | `decomposition/alternatives.py`: форвард, ванильный опцион на уровне защиты, коллар нулевой стоимости; для заёмщика — IRS, кэп, процентный коллар |
| Совмещённый профиль выплат с зоной отключения защиты | ✓ | `decomposition/profile.py`: зоны «хуже, чем без хеджа» (с причиной), «защита отключается», «коридор по конструкции» |
| Только публичные входы, источник и время у каждого числа | ✓ | `core/provenance.py`, трекер входов; белый список хостов в `marketdata/sources` |

### Каталог модификаторов

Все модификаторы каталога реализованы один раз и применяются к любому базису: барьер (все режимы
наблюдения, окно, ребейт с моментом выплаты, сдвиг BGK для дискретного), soft barrier, усреднение
(веса, пропуски, по цене/страйку, lookback), автоколл, память, накопление, целевое погашение (три правила
последнего платежа), плечо, локальные и глобальные кэпы/флоры, переустановка страйка, досрочное
прекращение (обратная индукция / LSMC), квантование, корзина (контроль положительной определённости),
спред, дискретные выплаты по базису, расчётные конвенции (источник фиксинга не взаимозаменяем). **✓**

### Схема сделки

Идентификация с генсоглашением и UTI, базис с источником и временем фиксинга и единицами, номинал с
графиком, расписания с календарями и лагами, выплата как база + модификаторы, расчёт с квантованием,
обеспечение, досрочное прекращение, **связанные сделки**, ссылки на термшит по каждому полю, версия схемы с
миграциями. **✓**
