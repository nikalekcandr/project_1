# Prism — независимый прайсер внебиржевых ПФИ российского рынка

Prism оценивает двусторонние внебиржевые деривативы «банк — корпоративный клиент» с рублёвой ногой
и **раскладывает цену сделки на компоненты**: справедливая стоимость по модели, издержки хеджирования
и исполнения, модельная неопределённость, кредитная составляющая (CVA с прокси-спредами), фондирование,
капитал и остаток — наценка. Отдельным выходом — **ванильная альтернатива** с тем же экономическим
назначением и совмещённый **профиль выплат** с отмеченными зонами, где предложенная структура перестаёт
защищать или становится хуже позиции без хеджа.

Все рыночные входы — только публичные (Мосбиржа, ЦБ РФ, Росстат, раскрытие эмитентов). Каждое число
в отчёте сопровождается источником, временем снятия и признаком происхождения (рынок / интерполяция /
экстраполяция / история / модель). Любая оценка воспроизводится «бит в бит» по аудиторской записи.


Образец полного отчёта: [`docs/sample_report.html`](docs/sample_report.html) (самодостаточный HTML,
открывается в браузере, светлая и тёмная темы). Матрица соответствия требованиям:
[`docs/requirements_coverage.md`](docs/requirements_coverage.md).

> **Демо-данные.** В репозитории нет реальных рыночных данных: встроенный снапшот на 15.10.2026
> сгенерирован внутренне согласованным (кривые, поверхности, кредитные спреды вымышленных эмитентов),
> помечен как ДЕМО и в каждом отчёте выводится крупным предупреждением. Парсеры публичных источников
> есть (см. «Рыночные данные»), но сборка полного снапшота из них — следующий шаг.

## Быстрый старт

```bash
pip install -e ".[web,dev]"          # Python ≥ 3.11; QuantLib нужен только для сверок
prism snapshot demo                   # демо-снапшоты в ./snapshots (или PRISM_SNAPSHOT_DIR)
prism templates                       # каталог из 53 структур
prism new fx_tarf --set target=7.5 -o trade.yaml
prism price trade.yaml --report out/tarf.html --record out/tarf.record.json
prism replay out/tarf.record.json     # воспроизвести оценку и сравнить побитно
prism compare examples/packages/*.yaml       # кредит + хедж от трёх банков: единая ставка «всё включено»
prism portfolio examples/trades --workers 4  # переоценка портфеля
prism validate                        # арбитражные проверки, QuantLib, МК против аналитики, регрессия
prism serve                           # веб-интерфейс на http://127.0.0.1:8000
```

`prism price` по умолчанию считает всё (греки с разбивкой, стрессы, сетку спот × вола, профиль у барьера,
альтернативы, XVA); `--fast` — облегчённый режим, `--price-only` — только цена.
Время на одном ядре: forward extra полностью — ~18 с, быстрый режим — ~8 с; переоценка 530 сделок
каталога — 157 с в один процесс, 70 с в четыре (`--workers 4`).

### Веб-интерфейс

`prism serve` — каталог структур с формой параметров, редактор термшита (YAML), оценка в трёх режимах,
разложение, профиль выплат, греки, стрессы, полный отчёт и аудиторская запись по ссылке, вкладка «Рынок»
(форвард ключевой ставки со ступенями на заседаниях, имплицированные вероятности решений ЦБ, CIP-базис,
репрайсинг кривых, QC снапшота) и вкладка сравнения предложений банков.

## Архитектура

Слои разделены строго; движок оценки не ходит за данными и получает только собранный контекст рынка.

```
снапшот (неизменяемый, с хэшем) → MarketContext (кривые, поверхности, кредит; кэш, сдвиги)
  → определение сделки (схема YAML, конвенции, расписания) → компиляция выплаты
  → движки (аналитика · PDE · дерево HW · Монте-Карло/LSMC) → риск (греки, сценарии, XVA)
  → разложение, альтернативы, пакеты, МСФО 9 → отчёт + аудиторская запись
```

| Каталог | Содержимое |
| --- | --- |
| `prism/core` | даты, базисы, календари (таблицы РФ/КНР + правила), расписания, происхождение данных |
| `prism/marketdata` | снапшот и хранилище, QC, контекст рынка со сдвигами, демо-данные, парсеры источников |
| `prism/curves` | мультикривая (ступени ЦБ, log-linear / monotone convex / кубический сплайн), КБД, FX и CIP, кредитные кривые (прокси), ИПЦ, товары |
| `prism/vol` | валютная поверхность в дельтах (SVI/SABR), страйковые поверхности, Дюпир, процентная вола (нормальная, caplet stripping) |
| `prism/instruments` | схема сделки, миграции, шаблоны термшитов (Jinja + YAML), описание сделки |
| `prism/payoff` | компиляция сделки в периоды и композиционная оценка выплат с модификаторами |
| `prism/models` | закрытые формулы, vanna-volga, МК (локальная вола, HW1F, мост Брауна, LSMC), PDE, дерево HW |
| `prism/pricing` | маршрутизатор движков, кросс-проверки, результат с перечнем входов |
| `prism/risk`, `prism/xva` | греки, сценарии и стрессы, профиль у барьера; экспозиции AMC, CVA/DVA, WWR, FVA, ColVA, KVA |
| `prism/decomposition`, `prism/packages` | разложение цены, ванильные альтернативы, профиль выплат; пакеты и МСФО 9 |
| `prism/reporting`, `prism/audit` | HTML-отчёт с SVG-графиками, поля НРД; аудиторская запись и воспроизведение |
| `prism/web`, `prism/cli.py` | FastAPI-интерфейс и командная строка |
| `prism/validation` | набор проверок, используемый `prism validate` и тестами |

Ядро собственное (numpy/scipy), QuantLib используется как независимый эталон в сверках. Причина —
российская специфика (ступенчатый короткий конец, производственный календарь, прокси-спреды, композиционные
модификаторы) составляет большую часть кода и в QuantLib всё равно писалась бы надстройкой; при этом
закрытые формулы и деревья сверяются с QuantLib до 1e-11.

## Описание сделки

Покрытие задаётся произведением **базовый актив × форма выплаты × модификаторы**. Сделка — набор ног,
нога — расписание, наблюдаемая величина и компоненты выплаты; модификаторы применяются к компоненту, ноге
или сделке целиком. Новая структура из термшита собирается конфигурацией: в `examples/trades/` — lookback,
best-of, quanto против composite, коллар на дифференциал Urals − Brent с мягким барьером — ни одна не
потребовала кода движка.

```yaml
identification:
  trade_id: FXE-2026-0457
  client: CLIENT_IMPORT
  trade_date: "2026-10-15"
  master_agreement: {type: RU_NFA, registered_in_repository: true}   # ст. 4.1 127-ФЗ
  uti: "RU-NRD-2026-000457"
purpose: {type: buy_fx, exposure_notional: 6000000, budget_rate: 90.0}
underlyings:
  X: {asset_class: fx, id: USDRUB, fixing: {source: CBR, lag_days: -1}}  # курс ЦБ устанавливается накануне
legs:
  - name: strip
    underlying: X
    schedule: {start: "2026-10-16", end: "2027-04-16", frequency: 1M, calendar: RU, payment_lag: 1}
    notional: {currency: USD, amount: {value: 1000000, ref: "п. 2.1 термшита"}}   # ссылка на место в документе
    components:
      - {kind: call, strike: 88.10}
      - kind: put
        strike: 88.10
        position: short
        modifiers: [{type: barrier, kind: in, direction: down, level: 78.0, monitoring: discrete, observation: daily}]
linked_trades: [{trade_id: KD-2026-1180, relation: condition_precedent}]
collateral: {regime: none}
```

* **Наблюдаемые:** `asset`, `performance`, `basket` (sum / worst_of / best_of / rainbow), `spread`
  (линейная комбинация базисов), `rate` (компаундирование, lookback и lockout для OIS), `cpi` (лаг, первая
  или уточнённая публикация, yoy), `realized_variance` / `realized_vol`, `credit`, `weather`.
* **Компоненты:** forward, call, put (с `cap_strike`), digital, range digital, asset, cash, fixed,
  fixed_compounded, float, cap, floor, coupon, redemption, variance, volatility, premium, protection,
  recovery, index_ratio; `position`, `gearing`, `notional_multiplier`.
* **Модификаторы** (каждый реализован один раз и работает с любым базисом):

| Модификатор | Параметры |
| --- | --- |
| `barrier` | in/out, up/down или двойной, непрерывное / дискретное (сдвиг BGK) / терминальное наблюдение, окно, ребейт и момент выплаты, `soft_width`, своя наблюдаемая |
| `averaging` | арифметическое / геометрическое среднее или экстремум (`max`/`min` — lookback), по цене или по страйку, веса, правило пропусков |
| `autocall` | даты, уровни, выплата, с какого наблюдения; `memory` — купон с памятью |
| `accrual` | диапазон, правило нерабочих дней, доля по дням или наблюдениям |
| `target` | цель по прибыли на единицу, в деньгах или по числу фиксингов; последний платёж full / partial / none |
| `leverage` | множитель, сторона (`below`/`above`/`always`), порог |
| `cap_floor` | локальные и глобальные кэпы/флоры (не коммутируют — порядок соблюдается) |
| `strike_reset` | forward start / cliquet: база (спот, предыдущий фиксинг), процент |
| `early_termination`, `exercise` | бермудское расписание → обратная индукция (дерево HW) или LSMC |
| квантование (`settlement.quanto`) | `quanto` (фиксированный курс) против `composite` (текущий курс) — разные цены |

Схема версионируется (`schema_version`, миграции 1.0 → 1.1); хэш канонического JSON сделки входит в
аудиторскую запись. Любое скалярное поле можно задать как `{value, ref}` — значение подставится, ссылка
на пункт термшита сохранится в `termsheet_refs` и попадёт в отчёт.

## Рыночные данные

* **Снапшот** — именованный, с таймстемпом, неизменяемый (`MappingProxyType`), с SHA-256 по каноническому
  содержимому. Хранилище только добавляет файлы (эксклюзивное создание, права только на чтение); исправление
  данных создаёт производный снапшот с `parent_id` и причиной (`prism snapshot correct ID --set Q=V --reason …`).
* **QC при загрузке:** устаревание относительно порога, пропуски в сетке сроков, выбросы к предыдущему дню,
  монотонность общей ATM-дисперсии, bid ≤ ask, покрытие календаря заседаний ЦБ ≥ 12 мес., флаг демо-данных.
* **Без тихих фоллбэков:** каждый вход регистрируется в трекере с видом происхождения; интерполированные,
  экстраполированные, исторические и модельные входы выводятся в отчёт отдельными строками и
  предупреждениями (например, поверхность GAZP без опционного рынка — историческая, с пометкой).
* **Источники:** парсеры ISS Мосбиржи (параметры КБД, RUSFAR, курсы TOM, фиксинги), XML ЦБ (официальные
  курсы, ключевая ставка, RUONIA), CSV Росстата (ИПЦ, первая и уточнённая публикации); загрузчик пускает
  только на публичные хосты из белого списка.
* **Конфигурация рынка** (`prism/data/market_config.yaml`): дисконтирование — RUSFAR под обеспечением,
  кривая КС без обеспечения; индексы и их кривые; FX-пары, CNY onshore против CNH; поверхности; товары с
  признаком торгуемого хеджа.

## Кривые и поверхности

* **Ступени ЦБ.** Короткий конец рублёвых кривых кусочно-постоянен по форварду со скачками на датах
  **вступления решений в силу** (календарь заседаний — загружаемый датасет). Побочный выход —
  имплицированная траектория: ожидаемое изменение и вероятности исходов на каждом заседании.
* Глобальный подбор кривой по всем инструментам (депозиты, FRA, OIS, IRS с компаундированием или простым
  средним, базисные свопы, FX-аутрайты), интерполяция log-linear / monotone convex (Hagan-West) /
  кубический сплайн по нулевым ставкам, гибрид «ступени + интерполяция»; плоская экстраполяция с флагом.
  Репрайсинг калибровочных инструментов: ≤ 0.32 б.п. (допуск 0.5).
* **FX:** форвардная кривая из пунктов, имплицированная рублёвая ставка из CIP и базис к onshore.
* **Вола:** валютная поверхность в дельтах (ATM DNS, RR/BF 25 и 10; спот/форвард-дельта,
  premium-adjusted), SVI с ограничением отсутствия бабочкового арбитража (SLSQP с точными якобианами) или
  SABR; интерполяция по общей дисперсии; проверки butterfly, calendar и неотрицательной форвардной
  дисперсии при каждом построении; sticky-delta / sticky-strike — параметр контекста. Локальная вола по
  Дюпиру. Процентная вола — нормальная, конвертация нормальная ↔ лог-нормальная, caplet stripping.
* **Кредит:** кривые интенсивности по прокси в порядке предпочтения: (1) спред облигаций эмитента к КБД,
  (2) спред сопоставимых эмитентов отрасли и рейтинга, (3) рейтинг → кумулятивные PD агентства
  (с пометкой «физическая мера»). Один модуль для CDS/CLN и для CVA.
* **ИПЦ** с явной сезонностью и лагом, **товарные** форвардные кривые с сезонностью и пометкой базисов без
  торгуемого хеджа, **акции** с дискретными дивидендами (Бюлер) и ставкой заимствования.

## Модели

| Класс | Движок |
| --- | --- |
| FX-форварды, свопы, NDF, IRS/OIS/FRA, базисные и кросс-валютные свопы, ZCIS | дисконтирование потоков по мультикривой |
| Ванильные FX-опционы | Garman-Kohlhagen с волой на страйке из поверхности |
| Барьеры, касания, двойные барьеры, DNT | Reiner-Rubinstein / Ikeda-Kunitomo / Hui + **vanna-volga** + **поправка на временную структуру** ставок, сноса и ATM-волы (PDE(структура) − PDE(плоские параметры) на одной сетке); дискретное наблюдение — сдвиг BGK 0.5826·σ·√Δt |
| Оконные, мягкие, path-dependent (TARF, accumulator, autocallable, range accrual, cliquet, lookback, корзины) | Монте-Карло: локальная вола Дюпира с мартингальной поправкой, антитетика, мост Брауна для барьеров, фиксированный seed, доверительный интервал |
| Бермудские свопционы, cancellable-свопы | триномиальное дерево Hull-White (сверено с QuantLib); прочие досрочные права — LSMC |
| Cap/floor, свопцион европейский | Башелье/Black покаплетно |
| Барьерный кэп | МК с HW1F |
| Азиатские | Тернбулл-Уэйкман (вола на страйке) или МК |
| Спред-опционы | Кирк (сверено с QuantLib) или МК |
| Variance / volatility swap | статическая репликация по страйкам с оценкой ошибки дискретизации; поправка на выпуклость для vol swap |
| CDS, CLN | интенсивность из прокси-кривой |
| Погодные | актуарно по историческим рядам (помечено: не риск-нейтральная мера) |

Маршрутизатор выбирает движок (аналитика → дерево → МК) и записывает причину; каждый движок возвращает
перечень фактически использованных входов с признаком модельности. Для барьеров отдельно считается
кросс-проверка VV против PDE с локальной волой — расхождение идёт в модельную неопределённость.

## Риск

* **Греки:** спот- и форвард-дельта, гамма (в т.ч. среднее по жизни сделки), вега итого и по срокам
  поверхности, ванна, волга, тета, ро по обеим валютам; key-rate DV01 раздельно по дисконтной и прогнозной
  кривой, PV01 по котировкам, гамма по ставке, вега по процентной воле; корреляционные и кросс-гамма.
  Для МК — общие случайные числа и сглаживание разрывов выплаты (без шума перевыпусков).
* **Стрессы:** КС ±500 б.п., рубль ±30%, одновременные сдвиги курса и ставки, шок ближайших заседаний,
  изменение наклона, вола +10 п.; сетка спот × вола; **профиль у барьера** — цена, дельта и гамма при
  подходе спота к барьеру с обеих сторон и предупреждение при близости.
* **XVA:** экспозиции по AMC на тех же путях, что и выплата (EE, ENE, PFE, EPE, эффективная EPE); неттинг по
  российскому генсоглашению (НФА/НАУФОР/АРБ — при регистрации в репозитарии, иначе брутто); режимы CSA
  (без, односторонний, двусторонний с порогом и MTA, MPoR); CVA/DVA по общим кредитным кривым; WWR —
  альфа-множитель и стохастическая интенсивность, коррелированная с курсом; FCA/FBA, ColVA, KVA с явными
  допущениями.

## Разложение, альтернативы, пакеты

* **Передача стоимости** = PV премии − справедливая стоимость для клиента = хеджирование и исполнение
  (спреды и гамма-издержки по срокам) + модельная неопределённость (½·|VV − LV|) + CVA + FVA/ColVA + KVA +
  **остаток**. Остаток показывается в рублях, в % номинала и в б.п. годовых на номинал-годы.
* **Альтернативы:** форвард по рынку, ванильный опцион на уровне защиты, коллар нулевой стоимости; для
  заёмщика — IRS, кэп и процентный коллар. Профиль: эффективный курс/ставка по сценарию «скачок к уровню»,
  зоны «хуже, чем без хеджа» (с причиной: плечо, обязательство после касания барьера, проданный опцион,
  уплаченная премия), «защита отключается» и «коридор без защиты по конструкции».
* **Пакеты:** кредит + обязательный дериватив, депозит + опцион, структурная нота — единая эффективная
  ставка «всё включено» и сравнение предложений разных банков (`prism compare`).
* **МСФО 9:** проект вывода об отделении встроенного дериватива (тесная связь по B4.3.5/B4.3.8 со ссылками
  на пункты), уровень иерархии справедливой стоимости, пункты, требующие суждения.

## Отчёт и аудит

Отчёт по сделке: итог для финансового директора, описание и назначение, разложение, альтернатива и
профиль, чувствительности, стрессы, CVA и XVA с методом прокси, рыночные входы с источником и временем,
модель и проверки, диагностика рынка, QC снапшота, МСФО 9, поля для сверки с НРД, аудиторский след.

Аудиторская запись: версия пакета, git-коммит и хэш исходников, версии моделей, id и хэш снапшота,
хэш конфигурации рынка, сделка целиком и её хэш, параметры оценки, seed, ключевые выходы в десятичном и
IEEE-754 hex-виде. `prism replay` повторяет оценку и сравнивает побитно; изменение кода или версий
моделей отражается в ответе.

## Валидация

`prism validate` (и тесты) проверяет:

* **арбитраж** на каждом построении: DF > 0 и убывают, форварды конечны, butterfly/calendar/форвардная
  дисперсия, монотонность цены по страйку и сроку, put-call паритет, KI + KO = ваниль, барьер ≤ ваниль;
* **QuantLib 1.44:** Garman-Kohlhagen, 8 типов барьеров с ребейтом, двойной барьер, DNT — до 6.5e-11 при
  ставках 5%, 16% и 30%; Кирк — до 1e-8; бермудский свопцион на дереве HW — расхождение ~0.02%;
* **МК против аналитики** на одинаковых допущениях (плоская улыбка): все в пределах 2σ после поправки на
  временную структуру (one-touch: было 3.9σ, стало 0.9σ);
* **устойчивость** аналитики и PDE при ставках 0–45%;
* **регрессию**: 29 эталонных сделок на привязанном снапшоте (`tests/golden/golden.json`); обновление
  требует `--update-golden --reason "…"`, причина и список изменившихся цен пишутся в историю файла.

`pytest` — 136 тестов (~1 мин): календари и расписания, неизменяемость и хэши снапшотов, QC, парсеры, репрайсинг
кривых и ступени ЦБ, поверхности, модели против QuantLib и МК, все 53 шаблона и все примеры конфигураций,
разложение, профиль, ColVA, пакеты, МСФО 9, воспроизведение бит в бит, CLI и веб-API.

## Ограничения и что дальше

* Демо-снапшот вместо реальных данных; парсеры источников есть, сборка полного ежедневного снапшота из
  них (включая опционный рынок Мосбиржи как якорь поверхности) — следующий шаг.
* Производственный календарь РФ загружен на 2024–2026, КНР — на 2025–2026; дальше — правило с флагом в
  отчёте. Таблицы нужно ежегодно обновлять и сверять с постановлением Правительства.
* Не реализованы: конвертируемые облигации (двухфакторная модель с кредитом), модель электроэнергии с
  возвратом к среднему и скачками (сейчас — помеченная оценка без торгуемого хеджа), CMS и CMS-спреды с
  выпуклостной поправкой, опционы на ОФЗ и TRS, dividend swap, свопы и опционы на кредитный спред,
  корреляционные свопы и FVA-соглашения, фьючерсы как калибровочные инструменты кривой, правила
  корректировки при корпоративных событиях, американские FX-опционы.
* МК-греки — общие случайные числа + сглаживание, а не pathwise/LR в чистом виде.
* KVA — упрощённый капитал (α·EEE·RW·норматив); требует сверки с действующими положениями Банка России.

Подробная матрица по каждому пункту требований — в [`docs/requirements_coverage.md`](docs/requirements_coverage.md).
