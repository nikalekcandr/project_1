# Сайт частного донора

Одностраничный сайт-визитка: без сборки, без сервера и без ежемесячной оплаты.

**👉 Полная инструкция — в [GUIDE.md](GUIDE.md)**: как редактировать, бесплатно запустить, подключить домен, продвигать и вести обращения.

## Быстрый старт

1. Открой `index.html` двойным кликом, и сайт появится в браузере.
2. Контакты, цветовая тема и анкета настраиваются в `assets/js/config.js`.
3. Тексты меняются прямо в `index.html`. Места для замены отмечены значком ✏️.
4. Чтобы опубликовать сайт, перетащи папку на [app.netlify.com/drop](https://app.netlify.com/drop) (подробнее — в разделе 4 гайда).

## Структура

```
index.html            — главная страница (все тексты)
privacy.html          — политика конфиденциальности (шаблон)
404.html              — страница «не найдено»
assets/js/config.js   — ⚙️ настройки: контакты, тема, анкета, аналитика
assets/css/style.css  — оформление и цвета
assets/js/main.js     — логика (обычно не трогать)
assets/img/           — фото, иконка, картинка для превью ссылок
docs/crm-template.csv — таблица для учёта обращений
robots.txt, sitemap.xml — для поисковиков
```
