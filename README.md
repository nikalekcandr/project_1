# BizForge — лаборатория бизнес-идей

**BizForge** помогает пройти путь от «хочу свой бизнес» до готового бизнес-плана с цифрами:
генерирует идеи, жёстко проверяет их по 14 критериям, строит бизнес-модель, считает рынок,
юнит-экономику и помесячную финансовую модель, оценивает риски методом Монте-Карло и собирает
бизнес-план для инвестора. Опционально подключается ИИ на базе Claude.

## Быстрый старт

Нужен Node.js 20 или новее.

```bash
npm install
npm run dev          # http://localhost:5173
```

При первом запуске открывается полностью заполненный демо-проект «ФитПульс», на котором видно работу всех разделов.

Другие команды:

```bash
npm test              # 60 тестов: расчётное ядро, ИИ-клиент, отрисовка всех страниц
npm run format        # форматирование кода (Prettier)
npm run typecheck     # проверка типов TypeScript
npm run build         # продакшен-сборка в dist/
npm run build:single  # один файл dist-single/bizforge.html — открывается двойным щелчком, без сервера
```

## ИИ-функции

Всё, кроме ИИ, работает без интернета и без регистрации. Чтобы включить ИИ:

1. Получите API-ключ в [Anthropic Console](https://console.anthropic.com/settings/keys).
2. Откройте **Настройки → ИИ на базе Claude**, вставьте ключ и нажмите «Проверить подключение».

Ключ хранится только в localStorage вашего браузера, не попадает в экспорт данных и отправляется
напрямую в `api.anthropic.com`. Если BizForge открыт как артефакт на claude.ai, ключ не нужен:
ИИ работает через аккаунт Claude зрителя (с его разрешения), а экспорт файлов — через диалог сохранения claude.ai. Модель по умолчанию — Claude Opus 5.5; в настройках можно выбрать
Sonnet 5.5 или Haiku 5.5 и глубину анализа. Структурированные задачи (оценки, холсты, риски, гипотезы)
используют JSON-схемы, поэтому ответы сразу подставляются в проект. ИИ никогда не перезаписывает
оценки, которые вы подтвердили данными.

## Методология

- **Оценка идеи.** Итог = взвешенное среднее оценок 1–5, приведённое к 0–100. Уверенность — средневзвешенная
  сила доказательств (предположение 0,2 · исследование 0,6 · данные 1,0). Вердикт учитывает и балл, и
  красные флаги (например, острота проблемы ≤ 2 или готовность платить ≤ 2).
- **Юнит-экономика.** ARPU = средний чек × покупок в месяц; срок жизни = 1 / отток; LTV = ARPU × маржа × срок
  жизни; окупаемость = CAC / (ARPU × маржа). Ориентиры: LTV/CAC ≥ 3, окупаемость ≤ 12 мес.
- **Финмодель.** Активные клиенты(t) = активные(t−1) × (1 − отток) + маркетинг/CAC + органика + рекомендации.
  Отток 100% моделирует разовые продажи. Безубыточность — первый месяц, с которого EBITDA ≥ 0 три месяца подряд.
  Потребность в деньгах — максимальная накопленная просадка свободного денежного потока. NPV и IRR
  считаются помесячно, с терминальной стоимостью = EBITDA последних 12 месяцев × мультипликатор.
- **Монте-Карло.** Каждый параметр задаётся треугольным распределением (минимум / наиболее вероятное / максимум)
  как множитель к базовому значению; генератор случайных чисел детерминирован (seed), поэтому результаты воспроизводимы.
- **Рынок.** Сверху вниз: клиенты × годовые расходы × доля сегмента × достижимая доля. Снизу вверх:
  целевые клиенты × цена × частота × охват × конверсия. Расхождение оценок больше чем в 3 раза — сигнал перепроверить данные.

Подходы опираются на Lean Canvas (Эш Мауря), Business Model Canvas (Александр Остервальдер),
«Спроси маму» (Роб Фитцпатрик), метод SCAMPER и практику венчурной оценки стартапов.

## Архитектура

```
src/
  core/            чистая расчётная логика без UI, покрыта тестами
    knowledge/     база знаний: отрасли, тренды, бизнес-модели, эксперименты, риски
    generator.ts   генератор идей и экспресс-оценка
    validation.ts  14 критериев, вердикт, красные флаги
    unitEconomics.ts, market.ts, finance.ts, monteCarlo.ts
    analysis.ts    сводный анализ проекта, проверки согласованности, индекс готовности
    businessPlan.ts сборка бизнес-плана в Markdown
  ai/              клиент Claude API (стриминг, JSON-схемы, fallback) и промпты
  platform.ts      возможности просмотрщика claude.ai, когда приложение опубликовано как артефакт
  state/           хранилище с сохранением в localStorage, импорт/экспорт
  ui/              страницы, компоненты и SVG-графики без сторонних библиотек
```

Стек: React 19, TypeScript, Vite, Vitest, официальный SDK `@anthropic-ai/sdk`. Графики — собственные SVG-компоненты
с подсказками при наведении, светлой и тёмной темой.

## Данные и приватность

Проекты, идеи и диалоги хранятся только в вашем браузере. Делайте резервные копии через
**Настройки → Экспорт всех данных** (JSON); отдельный проект можно экспортировать на странице «Мои проекты».
